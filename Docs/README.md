## 启动与操作

当前正式 PC 构建为 `Builds/PC/MRLab_E06_24371102.exe`。在项目根目录双击 [启动PC实验.cmd](../启动PC实验.cmd)，或直接运行该 exe。当前为 2026-10-28 小作业2修正版：保留实验桌作为场景设施，移除托盘，器皿和泡沫直接位于桌面。分发时必须包含整个 `Builds/PC` 文件夹。

| 操作 | 功能 |
| --- | --- |
| 左键点击烧杯 | 拿起试剂烧杯，随鼠标移动 |
| 手持时点击锥形瓶 | 倒入一份试剂，倒完继续拿着空杯 |
| 点击反应区外空闲台面 | 放下烧杯，拒绝台外或与其他烧杯重叠的位置 |
| 右键拖动／滚轮／中键拖动 | 旋转／缩放／平移视角 |
| Home | 恢复初始视角 |
| Esc | 放回本次拿起的位置 |
| R 或重置按钮 | 恢复器材、补满试剂并清空本轮反应 |
| 1—4／Enter | 拿起相应烧杯／添加所持试剂 |

每种试剂只有一份，空杯不能重复添加。倾倒过程中暂不能换杯或放下，反应期间可以继续加入尚未使用的试剂。

## 实验设计与当前边界

实验台包含一只开放锥形瓶和四只试剂烧杯；托盘已移除。试剂为过氧化氢溶液、洗洁精、食用色素和酵母催化液，色素可选。当前采用酵母催化方案，与计划书中的碘离子催化示例不同。

- 过氧化氢与催化液接触后启动产气；无洗洁精时气体逸散，不形成稳定的大量泡沫。
- 加入洗洁精后，新生成气体形成泡沫并喷出、落下和堆积；后加洗洁精不能收回此前逸散的气体。
- 色素只影响颜色；反应结束后添加剩余试剂不会使已耗尽的过氧化氢重新产气。
- 采用归一化有限反应物和固定步长更新。当前约 1 秒诱导、7 秒反应窗口属于教学演示时序，不是实测动力学。
- 当前是点击触发的一份式倾倒，尚无按倾角连续流量、真实体积、倒偏洒出或容器接满的物料台账；不用于真实配方、温度或危险程度预测。
