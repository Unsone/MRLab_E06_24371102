# 空烧杯：去除混元误建的水面隔板

这是修正后的空烧杯版本。项目根目录的 `OpenBeakerInBlender.cmd` 已指向本目录的 `Beaker_Empty_10cm.blend`。

之前的 `Beaker_Repaired_10cm` 错把混元生成的水面圆形隔板保留成了内底，导致杯腔只有约 2.37 cm 深。此次按用户指出的问题去除了这个隔板，并补齐隔板以下原本缺失的内壁。旧版本保留为过程记录，不再作为最终模型。

## 处理内容

1. 隔板位于旧模型底面上方约 7.63 cm。沿其上方的内壁轮廓分离，删除隔板及相邻需要重接的部分，共 968 个面。
2. 保留生成模型的外壁、杯口、杯嘴和上部内壁，将现有内壁轮廓向下延伸，连接到靠近真实杯底的位置。并非简单删掉圆面后留下开放缺口。
3. 保留杯底，调整底部平滑权重，使内壁与底部相连，模型整体总高仍为 10 cm。
4. 保留玻璃材质和可编辑的平滑、细分修改器。Blender 集合内另存原始算法模型和上一次浅腔版本的隐藏副本。

## 实际验证

- 最终总高：约 10.000 cm。
- 中心内深：约 9.549 cm，检查从杯口最高处计算。
- 中心底厚：约 4.51 mm；底部在修改器作用后略有变化。
- 杯腔内 7 个向下探测点均直接命中约 4.5～4.7 mm 高度的杯底，旧水面位置没有阻挡。
- 在 4 个高度、24 个方向，共 96 处检查内外壁，采样位置的最小壁厚约 3.12 mm。这是采样检查，不是全表面壁厚下界证明。
- 最终计算网格：开放边 0，非流形边 0。杯口连通空腔，杯壁与底部构成闭合的玻璃实体；闭合实体不表示杯口被填上。
- 实际渲染了实体视图、玻璃视图和半剖面图，已检查内腔连续延伸到底部。

具体记录见 `empty_repair_report.json`。这些是几何检查，未进行流体仿真；Unity 的水体与碰撞器需按实验逻辑另外配置。

## 文件

- `Beaker_Empty_10cm.blend`：Blender 主文件。
- `Beaker_Empty_10cm.fbx`：导出修改器后的几何。
- `Beaker_Empty_10cm.glb`：包含透射材质的交换模型。
- `empty_clay.png`：实体视图。
- `empty_glass.png`：玻璃视图。
- `empty_section.png`：检查用半剖面图。

半剖面对象仅用于展示内腔，默认隐藏，未导出到 FBX/GLB。正式模型是 `Beaker_Empty_10cm`，没有真的切掉半边。

Unity 导入 FBX 后仍需使用 URP 的透明材质，Blender 的折射节点不会通过 FBX 自动转换。后续已接入 PC 主场景，Unity 副本位于 `Assets/_Project/Art/Models/Hunyuan`，交互仍由独立根节点负责。

复现脚本：`../Hunyuan3D/repair_empty_beaker.py`。输入上一版 `.blend`，输出本目录；混元原始结果仍在 `../Hunyuan3D/Outputs/20261022_152840_69d986/`。
