## 成分决定现象

| 容器内成分或操作 | 现象 |
| --- | --- |
| 缺少过氧化氢或酵母催化液 | 无明显催化产气 |
| 过氧化氢 + 酵母催化液，无洗洁精 | 产气、细小气泡逸出，不形成稳定牙膏状泡沫柱 |
| 两者接触时已经有洗洁精 | 大量稳定泡沫快速喷出，弯曲下落，折叠堆积 |
| 先反应，过一段时间才补洗洁精 | 剩余反应物产生的气体才形成稳定泡沫，最终量较少 |
| 反应耗尽后才补洗洁精 | 不重新喷发 |
| 不加色素 | 正常反应，白色泡沫 |
| 加色素 | 液体染色，此后生成的泡沫带颜色，产气量不变 |
| 反应中补色素 | 新生成的泡沫染色，已离开容器的白泡沫不瞬间改色 |

原理依据：[Science Buddies 催化反应教学](https://www.sciencebuddies.org/teacher-resources/lesson-plans/catalase-reaction-rate)；[Buffalo Museum of Science（色素可选）](https://www.sciencebuff.org/scienceactivity/elephant-toothpaste/)。

酵母中的过氧化氢酶促进过氧化氢分解，洗洁精稳定气泡，色素只负责染色。任意顺序“允许添加”不代表等待时间不同也会得到相同泡沫量。

## 视觉与实现

`ViscousFoam` 使用连续光滑管状网格，模拟泡沫条从瓶口挤出后的重力下落、弯曲和自身接触，形成不规则盘绕堆积。材料使用白色/染色两个 URP 材质；喷出时记录颜色。原来的独立球体泡沫已替换。容器改为锥形烧瓶，托盘扩大以接住堆积物。

这是定性的教学与视觉模型：使用归一化的有限过氧化氢、12 秒演示反应和衰减产气率，不代表实测浓度、流速、温度或精确流体力学。特效不应被解释为任意实际配方都具有相同喷发高度。

## 验证

编辑器测试覆盖 24 种排列、色素有无的相同产气量、无洗洁精、延迟加洗洁精、耗尽后补加不重启、后加色素仅染新泡沫、并发添加拦截和重置。

命令行参数 `--demo-verify` 在独立程序验证实际倾倒回调、无色素喷发、落下堆积、无洗洁精气泡、反应结束后补加及重置，并保存各阶段截图。图形验收需在可见窗口中进行，后台隐藏窗口可能只得到黑图。
